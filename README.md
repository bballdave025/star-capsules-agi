# STAR Capsules for Amazon AGI Interview Prep

This repository collects **STAR-format interview capsules** (Situation–Task–Action–Result) aligned with **Amazon’s Leadership Principles (LPs)** and technical/functional assessments.  
The goal is to prepare concise, reusable answers that demonstrate impact, clarity, and authenticity.

---

## Repository Structure

- **00_Guidelines.md**  
  Ground rules for building and editing capsules (e.g., prolix first → trim later, 2–4 examples per LP, cross-stage variety).

- **Leadership_Principles/**  
  Each LP has its own folder with subfiles organized by life/career stage:
  - `stage1_education.md` → examples from academic work (physics, ML coursework).  
  - `stage2_captioncall.md` → Sorenson/CaptionCall speech-science and dataset curation work.  
  - `stage3_amazon.md` → warehouse/merchandising/AGI prep examples.  
  - `stage4_rmfb.md` → independent research projects (e.g., RMFB).  

- **STAR_Capsules/**  
  Standalone capsules that can be referenced across LPs.  
  Example:  
  - `rmfb_scale_trust.md` (scale + explainability)  
  - `rmfb_ambiguity.md` (classification edge cases)

---

## Workflow

1. **Draft prolix**: Capture full detail, even if long-winded.  
2. **Trim**: Reduce to 3–5 tight sentences per capsule.  
3. **Map**: Link each capsule to at least one Leadership Principle.  
4. **Practice**: Read aloud for timing (goal: 1–2 minutes spoken).  
5. **Iterate**: Keep both “full” and “concise” versions under version control.  

---

## Goals

- **Coverage**: At least 2 examples per LP, ideally spanning multiple life stages.  
- **Flexibility**: Reuse one capsule across several LPs (e.g., RMFB ambiguity for *Dive Deep* and *Are Right, A Lot*).  
- **Balance**: Mix technical/functional capsules with people/ownership stories.  
- **Clarity**: Deliver authentic, concise STAR answers under interview conditions.
